2. Electricity bill calculation
File: Main.java
import java.util.Scanner;
public class Main {
 public static void main(String[] args) {
 Scanner sc = new Scanner(System.in);
 System.out.print("Enter units consumed: ");
 int units = sc.nextInt();
 if (units < 0) {
 System.out.println("Units cannot be negative.");
 return;
 }
 double bill;
 if (units <= 100)
 bill = units * 1.50;
 else if (units <= 200)
 bill = 100 * 1.50 + (units - 100) * 2.50;
 else
 bill = 100 * 1.50 + 100 * 2.50
 + (units - 200) * 4.00;
 System.out.println("Electricity Bill: Rs. " + bill);
 }
}

11. Palindrome number
File: Main.java
import java.util.Scanner;
public class Main {
 public static void main(String[] args) {
 Scanner sc = new Scanner(System.in);
 System.out.print("Enter a number: ");
 int n = sc.nextInt();
 int original = n;
 int reverse = 0;
 while (n > 0) {
 int digit = n % 10;
 reverse = reverse * 10 + digit;
 n = n / 10;
 }
 if (original >= 0 && original == reverse)
 System.out.println("Palindrome");
 else
 System.out.println("Not Palindrome");
 }
}

13. Factorial using loop
File: Main.java
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int n = sc.nextInt();

        long fact = 1;

        for (int i = 1; i <= n; i++) {
            fact = fact * i;
        }

        if (n < 0)
            System.out.println("Invalid Input");
        else
            System.out.println("Factorial: " + fact);

        sc.close();
    }
}

Build and execution quick reference
Maven: mvn clean package — compiles, tests (if configured), and packages a JAR in target/.
Maven tests: mvn clean test package.
Gradle: gradle clean build — builds and tests the Gradle project; JAR is normally in build/libs/.
Ansible: ansible-playbook app.yml.
Project organization reminder
Do not put all classes named Main into one Java project. Each numbered standalone exercise should have its own project
or a distinct package/class name. In Maven projects, Java source goes under src/main/java and JUnit test source goes
under src/test/java. In a Maven JAR, a Main class is not automatically executable with java -jar unless a Main-Class
manifest entry is configured; the pipeline here builds and publishes the JAR artifact as requested.
